A modern, fully responsive web application to track daily market prices of essential commodities in Bangladesh. It provides up-to-date pricing, market comparisons, and price change alerts, completely localized in Bengali.

## 📖 Short Description
**বাজার দর (BazarDor)** is designed to help users stay informed about the daily fluctuations in market prices. From rice and lentils to fish and meat, the platform aggregates data and presents it in an easy-to-read format. It features a modern UI, secure authentication, and a personalized experience for users to track their daily grocery budgets.

## 🛠️ Technologies Used

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **UI Components:** [HeroUI](https://www.heroui.com/)
*   **Authentication:** [Better Auth](https://www.better-auth.com/)
*   **Database:** [MongoDB](https://www.mongodb.com/)
*   **Icons & Animations:** React Marquee Text, Lucide Icons

## ✨ Key Features

1. **🇧🇩 Fully Localized in Bengali:** 
   All prices, dates, and UI text are dynamically converted to Bengali numerals and script (e.g., ১৪৮ টাকা, ৪.৮%) providing a seamless native experience for users.
2. **📈 Real-time Price Change Tracking:** 
   An animated marquee ticker and dedicated homepage sections instantly highlight which products have increased (▲) or decreased (▼) in price today.
3. **📂 Dynamic Category Filtering:** 
   Users can effortlessly browse products by specific categories (e.g., Rice, Lentils, Oil). The navigation bar features active-state highlighting to show the current category.
4. **🏪 Detailed Market Breakdown:** 
   A comprehensive product details page displays the lowest, highest, and average prices across different markets and divisions in Bangladesh, helping users find the best deals.
5. **🔒 Secure Authentication & Private Routes:** 
   Powered by Better Auth, the platform ensures that sensitive data and detailed price breakdowns are protected. Unauthenticated users are automatically redirected to the sign-in page.
